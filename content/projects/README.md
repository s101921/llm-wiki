# Projects — 專案知識層

每個專案一個子資料夾（slug 命名，全小寫連字符）。

**放什麼：** 這個專案學到的東西（知識）
**不放什麼：** 程式碼、設計檔、客戶資料（留在原目錄）

## 每個專案資料夾的標準結構

```
projects/[project-slug]/
├── overview.md    ← 專案是什麼、目標、工具、狀態
├── learnings.md   ← 過程中的發現（隨時 append）
└── extracted.md   ← 已提煉進 wiki 的項目（防止重複）
```
