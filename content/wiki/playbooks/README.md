# Playbooks — 多 Skill 組合的完整執行流程

這裡存放「marketing plugins」：把多個 skill 串聯成一個有明確輸入輸出的完整流程。

## 與其他頁面的區別

| | Playbook | Workflow/Skill |
|--|---------|----------------|
| 層次 | 編排層（串聯多個 skill） | 執行層（單一操作） |
| 寫法 | 指令性（LLM 照步驟執行） | 指令性（單一 SOP） |
| 輸入輸出 | 明確定義 | 視情況 |
| 引用 | 引用多個 workflow 頁 | 引用 concepts/tools |

## 現有 Playbooks

（目前無）

## 使用方式

跑一個 playbook 時，跟 Claude 說：
「執行 [[wiki/playbooks/xxx]]，輸入是 ___」
