**AI 圖像生成**

**通用強約束 Prompt 語法指南**

*解決特徵偏移 · 環境違和 · 隨機干擾三大穩定性痛點*

適用所有 AI 圖像工具（Nano Banana、即夢 Seedream、Midjourney、DALL-E
等）

**為什麼需要「強約束」Prompt？**

AI
圖像生成工具的核心矛盾在於：模型具有「創意自由」的天性，但商業應用需要「高度可控」的輸出。弱約束的
Prompt 讓 AI 有太多自由發揮空間，導致三類核心痛點：

+-----------------------+-----------------------+-----------------------+
| **⚠️ 特徵偏移**       | **⚠️ 環境違和**       | **⚠️ 隨機干擾**       |
|                       |                       |                       |
| 人像或物品替換        | 新嵌入元              | 修改局部時，AI        |
| 後，五官比例、膚色、  | 素的光影方向、色溫、  | 擅自變動不需修改的背  |
| 特徵發生非預期改變。  | 透視角度與原圖不符，  | 景、文字或其他元素。  |
| 角色「換了一個人」。  | 產生明顯「剪貼感」。  |                       |
+-----------------------+-----------------------+-----------------------+

強約束 Prompt 的設計邏輯，是透過明確的語法結構，告訴
AI「可以動什麼」、「不可以動什麼」，將創意自由空間壓縮到你指定的範圍內。

**強約束 Prompt 的五大核心原則**

**原則一：操作範圍必須明確宣告**

每個指令都要清楚區分「允許修改區」與「鎖定區」。沒有宣告鎖定的部分，AI
會自行判斷，導致隨機干擾。

+-----------------------------------+-----------------------------------+
| **❌ 弱約束（不穩定）**           | **✅ 強約束（穩定）**             |
|                                   |                                   |
| 將背景改為夜晚場景                | 僅修改畫面背景為夜晚都市場景      |
|                                   | ，前景人物的服裝、髮型、表情、姿  |
|                                   | 態與原圖完全一致，不得有任何改變  |
+-----------------------------------+-----------------------------------+

**原則二：修改項目必須條列，且附帶鎖定聲明**

要修改多個地方時，用編號條列每一項修改，並在結尾統一加上鎖定聲明，而非在自然語言中混合描述。

+-----------------------------------+-----------------------------------+
| **❌ 弱約束（不穩定）**           | **✅ 強約束（穩定）**             |
|                                   |                                   |
| 改一下光影，顏色也                | 請依序修改以下三點： 1.           |
| 調整一下，字體換掉，其他保持不變  | 整                                |
|                                   | 體光影改為柔和側光（從右方射入）  |
|                                   | 2. 色調調整為低飽和莫蘭迪暖色系   |
|                                   | 3. 標題字體改為無襯線現代體       |
|                                   | 以上三點之外，畫                  |
|                                   | 面所有細節必須與原圖完全一致，不  |
|                                   | 得新增、刪除或改變任何其他元素。  |
+-----------------------------------+-----------------------------------+

**原則三：用具體參數取代模糊形容詞**

「自然」、「和諧」、「適合」這類詞語對 AI
而言是高度模糊的。換成可量化或可驗證的描述，AI 才能精確執行。

  ----------------------------------------------------------------------------------------
  **❌ 模糊（AI 自行詮釋）**          **✅ 具體（AI 可精確執行）**
  ----------------------------------- ----------------------------------------------------
  光線自然一點                        光源方向為右側 45° 柔和漫射光，無強烈陰影

  顏色和諧                            整體色溫統一為 5000K 暖白，飽和度降低 30%

  嵌入後要融合                        嵌入物件需匹配原圖透視角度與光源方向，邊緣羽化處理

  畫面清晰一點                        輸出解析度 4K，細節銳化，無模糊或噪點
  ----------------------------------------------------------------------------------------

**原則四：操作動詞要精確，避免歧義**

動詞的選擇直接影響 AI 的執行範圍。以下是常用動詞的精確用法：

  ---------------------------------------------------------------------------------------------
  **語法參數**        **作用說明**               **範例值**
  ------------------- -------------------------- ----------------------------------------------
  **僅修改**          只改這一項，其他全鎖定     「僅修改標題文字顏色為白色」

  **完整替換**        整體置換，保留其他一切     「完整替換背景為草地場景，保留前景所有元素」

  **嵌入 / 合成**     放入指定位置並做融合處理   「將圖2嵌入圖1紅框位置，模擬透視與光影」

  **像素級鎖定**      強調完全不可動             「其餘區域像素級鎖定，不得有任何變動」

  **風格轉換**        只改渲染外觀，不改結構     「風格轉換為水彩插畫，禁止增減畫面元素」

  **隔離處理**        只對特定層操作             「隔離文字層單獨處理，背景底圖不得變動」
  ---------------------------------------------------------------------------------------------

**原則五：輸出規格在結尾統一宣告**

將解析度、比例、格式等輸出規格統一放在 Prompt
最後，避免分散在描述中造成混淆。

+-----------------------------------------------------------------------+
| **📐 輸出規格模板**                                                   |
|                                                                       |
| **輸出規格：\[比例\] \[解析度\] \[格式\]，例如：輸出 16:9、4K         |
| 高清、無浮水印。**                                                    |
+-----------------------------------------------------------------------+

**通用強約束 Prompt 模板庫**

以下五類模板對應五種最常見的操作場景，每個模板都已內建強約束語法。使用時將
\[ \] 中的內容替換為實際需求即可。

  -----------------------------------------------------------------------

適用場景：將整張圖轉為特定渲染風格，但不改變任何畫面元素（構圖、內容、佈局完全保留）。

|                                                                       |
| **請將整張圖片完整轉換為                                              |
| \[目標風格\]，不得增添或刪減任何元素，僅調整材質與渲染表現。**        |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **✦ 完整範例 A｜轉換為插畫風格**                                      |
|                                                                       |
| 請將整張圖片完整轉換為吉卜力動畫插畫風格，                            |
|                                                                       |
| 不得增添或刪減任何元素（人物位置、背景構圖、文字內容全部保留），      |
|                                                                       |
| 僅調整材質與渲染表現，顏色轉為溫潤飽和的插畫配色，                    |
|                                                                       |
| 筆觸呈現手繪水彩質感。                                                |
|                                                                       |
| 輸出比例與原圖相同，4K 高清。                                         |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **✦ 完整範例 B｜轉換為攝影寫實風格**                                  |
|                                                                       |
| 請將整張圖片完整轉換為商業攝影寫實風格，                              |
|                                                                       |
| 保留所有元素的位置、比例與構圖，                                      |
|                                                                       |
| 禁止新增或移除任何物件，                                              |
|                                                                       |
| 僅調整材質質感為真實物理材質、光影為柔和棚拍三點布光。                |
|                                                                       |

  *🔒
  強約束關鍵語：「不得增添或刪減任何元素」＋「僅調整材質與渲染表現」是風格純化的核心鎖定語。*

+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **✦ 完整範例｜海報局部調整**                                          |
|                                                                       |
| 請修改此海報圖，依序執行以下 3 項變更：                               |

|                                                                       |

**進階技巧：結構化參數語法（類 JSON 風格）**

當操作需要精確控制多個參數，且普通自然語言容易被 AI 混淆時，可採用類
JSON
結構化寫法。這種寫法將「修改對象」與「參數值」明確配對，大幅降低歧義。

  -----------------------------------------------------------------------
  *💡 此技巧在即夢 Seedream 與支援長 Prompt 的模型（如 GPT-4o
  Image、Flux）上效果最明顯；Nano Banana
  亦支援，但建議搭配自然語言補充說明。*

  -----------------------------------------------------------------------

**結構化語法範例：多參數圖像編輯**

+-----------------------------------------------------------------------+
| **✦ 結構化參數寫法範例**                                              |
|                                                                       |
| 請依據以下參數修改圖片：                                              |
|                                                                       |
| {                                                                     |
|                                                                       |
| \"操作模式\": \"局部修改\",                                           |
|                                                                       |
| \"修改項目\": \[                                                      |
|                                                                       |
| { \"對象\": \"背景\", \"動作\": \"替換\", \"目標\": \"現代都市夜景\", |
| \"色溫\": \"3000K 暖橘\" },                                           |
|                                                                       |
| { \"對象\": \"主標題\", \"動作\": \"字色修改\", \"目標色\":           |
| \"#FFFFFF\", \"字體\": \"不變\" },                                    |
|                                                                       |
| { \"對象\": \"主角人物\", \"動作\": \"服裝替換\", \"參考圖\":         |
| \"圖2\", \"鎖定\": \"臉部/髮型/姿態\" }                               |
|                                                                       |
| \],                                                                   |
|                                                                       |
| \"鎖定區域\": \"以上修改項目之外的所有元素\",                         |
|                                                                       |
| \"輸出規格\": { \"解析度\": \"4K\", \"比例\": \"原圖相同\",           |
| \"浮水印\": \"無\" }                                                  |
|                                                                       |
| }                                                                     |
+-----------------------------------------------------------------------+

即使 AI 不完全解析 JSON
格式，這種結構化寫法也能明確傳達「每個修改都是獨立的」、「修改項目有明確邊界」的語意，讓輸出比純自然語言更穩定。

**速查表：強約束關鍵語彙**

  ---------------------------------------------------------------------------------------------------
  **目的**               **強約束語彙**                                   **對應的痛點**

  **鎖定未修改區域**     **其餘區域完全保持不變 / 像素級鎖定**            隨機干擾

  **限制修改範圍**       **以上 \[N\] 項之外，一切不得改變**              隨機干擾

  **風格轉換不改結構**   **禁止增添或刪減任何元素，僅調整渲染**           隨機干擾

  **文字層隔離**         **背景底圖及所有非文字元素完全不得變動**         隨機干擾

  **嵌入無縫融合**       **模擬透視角度、匹配光源、統一色溫、邊緣羽化**   環境違和

  **條列修改項目**       **依序執行以下 \[N\] 項變更：1. 2. 3.**          隨機干擾

  **具體數值約束**       **使用色碼 #RRGGBB、倍數、度數等可量化描述**     特徵偏移 / 環境違和

**課堂練習建議**

每個練習都聚焦在「強約束語法」的運用，建議先寫弱約束版本，再改寫為強約束版本，比較兩次輸出的差異。

+-----------------------------------------------------------------------+
| **練習 1 --- 風格轉換** 解決痛點：隨機干擾                            |
|                                                                       |
| 找                                                                    |
| 一張含有多種元素的圖片（如產品情境圖），先用「改成插畫風格」生成，再  |
| 用模板一的強約束語法重新下指令，對比哪些元素在弱約束版本中被改動了。  |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **練習 2 --- 條列修改** 解決痛點：隨機干擾                            |
|                                                                       |
| 準備一張有文字的海報，用模板二一次修改 3                              |
| 個項目（如顏色、字體、背景），觀察強約束語法能否讓 AI                 |
| 精確執行，而不更動其他元素。                                          |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **練習 3 --- 框線嵌入** 解決痛點：環境違和                            |
|                                                                       |
| 用手機截圖工具在一張場景圖上畫一個紅                                  |
| 框，上傳後用模板四進行嵌入，加入透視與色溫要求，觀察是否產生剪貼感。  |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **練習 4 --- 特徵鎖定** 解決痛點：特徵偏移                            |
|                                                                       |
| 上傳一張人像，先用「換一件衣服                                        |
| 」生成，再用模板五加入詳細特徵鎖定清單重試，比較臉部特徵的保留程度。  |
