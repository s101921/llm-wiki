# 用途指引：人像（Portrait）

> 當主SKILL.md判斷用途為「人像」時，載入此檔案。

---

## 人像的核心原則

人像不是拍人，是**捕捉一個人的狀態與情緒**。
技術是服務情緒的，不是目的本身。

---

## 必描述的人像元素

每次人像Prompt都必須包含：
- 髮型（長短/顏色/髮質）
- 服裝（風格/材質/色彩）
- 表情（具體情緒，不用「美麗」這種模糊詞）
- 姿態（站/坐/動作）
- 視角（正面/側面/俯角/仰角）
- 與鏡頭的關係（看鏡頭/看向他處/閉眼）

---

## 依風格光譜的人像處理

### 寫實端人像（1-3分）
目標：有呼吸感的真實人物，情緒大過完美
- 皮膚：真實質感，允許有毛孔/細紋
- 光線：窗邊自然光/環境光，不刻意
- 背景：真實環境，適當散焦
- 必加詞：`natural skin texture, environmental portrait, candid feel, real person authenticity`

### 平衡端人像（4-6分）
目標：精緻但有情緒，商業感中有人性
- 皮膚：後製感克制，真實但乾淨
- 光線：蝴蝶光/倫勃朗光，有設計但不過度
- 背景：簡潔有質感
- 必加詞：`editorial portrait, controlled lighting, fashion photography, intentional gaze`

### 創意端人像（7-10分）
目標：人物與超現實元素融合，人成為概念的載體
- 皮膚：可以有光效/材質覆蓋/特效
- 光線：戲劇性，可以是非自然光
- 背景：超現實環境
- 必加詞：`conceptual portrait, surreal human, person as symbol, otherworldly being`

## 人像通用技術詞

```
portrait photography, detailed facial features,
professional headshot quality, skin detail,
bokeh background, prime lens aesthetic
```

## 人像通用 Negative Prompt

```
deformed face, extra limbs, bad anatomy,
plastic skin, airbrushed, uncanny valley,
blurry face, distorted features
```
