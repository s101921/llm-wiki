# 視覺語言：字體 & 排版 & 文字設計

> 此檔案記錄使用者對文字設計、排版、圖文關係的審美偏好。
> 當畫面需要文字元素時載入此檔案。
> 內容透過使用者上傳的參考圖片逐步萃取累積。

---

## 核心排版哲學

**文字越少，每個字越有重量。**
使用者偏好「留白是主角，文字是點睛」的排版策略——
不是用文字填滿空間，而是讓文字在空間中「漂浮」。

---

## 文字量策略

### 極簡文字（首選）——圖10 SoftBank
- 畫面中只有一句話或一個品牌名
- 文字量少到幾乎是「留白中的一個呼吸」
- 其餘資訊（法律條文、小字說明）縮到最小，退出視覺焦點
- **關鍵詞：** `minimal text, single headline, breathing space around text, text as accent not filler`

---

## 文字與圖像的關係

### 縱排漂浮型（圖10 SoftBank）
- 文字縱向排列（適合日文/中文），漂浮在人物旁的空白處
- 文字不在角落、不在框框裡，而是與人物呼吸空間共存
- 文字位置感覺是「剛好在那裡」，不是被對齊工具放置的
- **關鍵詞：** `vertical text layout, floating text beside subject, text in breathing space, organic text placement, Japanese vertical typography`

---

## 字體風格偏好

### 目前已知
- 極簡無襯線或細明體系——乾淨、不搶戲
- 字重偏細（Light）或標準，不用粗黑體（在極簡風格中）
- 文字顏色：白色或淺色為主，疊在圖像上不用黑框

## 字重對比排版（圖11 HAVE YOU）

### 三層字重層次
- **第一層（超大粗黑）**：畫面最頂部，字體極大、字重 Black，製造壓迫感與視覺衝擊
- **第二層（中等標準）**：主要訊息，字重 Regular 或 Medium，左對齊，易讀
- **第三層（極小弧線）**：補充文字，字體極小，沿弧線/曲線排列，製造動態感

三層同時存在，靠**大小落差**製造層次，而非靠顏色區分。

### 字重對比原則
- 大標題用到極端（Black）——不用中間值
- 小字用到極端（極小、路徑彎曲）——不用平凡的正常小字
- 中間層負責「說清楚」，上下層負責「製造張力」

**關鍵詞：**
```
extreme font weight contrast, oversized black weight headline,
three-tier typographic hierarchy, bold headline with small body text,
text size contrast, Black weight display font
```

---

## 弧線/路徑文字（圖11 HAVE YOU）

- 文字沿弧線、圓形或斜線排列，打破水平/垂直的規矩感
- 可以是圓形路徑（文字繞圈）、斜弧（文字沿曲線流動）、垂直旋轉
- 弧線文字通常是**補充資訊**，不是主標題——它是「畫面的細節驚喜」
- 與大標題的直線排列形成對比，製造動態感

**關鍵詞：**
```
text on arc path, circular text layout, curved text arrangement,
text following path, rotated text, typographic movement,
text as dynamic element
```

---

## 圖文色彩對比（圖11 HAVE YOU）

- 大標題用飽和強色（紅/電藍/黑），背景保持奶白/淺色
- 文字顏色即是畫面的點綴色——文字本身承擔色彩衝擊的功能
- 背景越乾淨，文字顏色越有力量

**關鍵詞：**
```
bold red headline on cream background, saturated text color,
high contrast typography, color as typographic element
```

## 中文字體設計偏好（圖12 字體集）

### 核心發現
使用者對中文排版有**極廣的審美接受度**，但有幾個共同的底層邏輯：
> 「文字本身要有個性——不管是殘缺、錯位、混搭、還是極簡，都不能是『安全的標準字』」

---

## 五種偏好手法

### 1. 書法 × 印刷體混搭
- 手寫草書/書法字 與 現代無襯線/黑體 同時出現
- 兩種截然不同的氣質衝突共存，製造時代感張力
- 代表：以愛之名、夢想空間、法曲·汲華
- **關鍵詞：** `calligraphy mixed with sans-serif, handwritten brush stroke with modern typeface, traditional meets contemporary typography`

### 2. 故意殘缺 / 不完整筆畫
- 字的筆畫刻意切掉、缺角、或不封閉
- 「缺陷」本身是美感——不完整反而更有記憶點
- 代表：缺陷美
- **關鍵詞：** `intentionally incomplete letterform, deconstructed character, broken stroke design, imperfect typography as aesthetic`

### 3. 文字錯位 / 非對齊排列
- 字與字之間刻意錯開，不在同一基準線上
- 大小不一、位置偏移，製造視覺節奏
- 代表：缺陷美、優雅招門、夢想空間
- **關鍵詞：** `misaligned text layout, off-grid typography, staggered character placement, intentional misregistration`

### 4. 中英文混排
- 中文大字為主體，英文小字為輔助說明
- 兩種文字在同一畫面形成大小對比與文化層次
- 代表：橘子廚房、龍來步道、優雅招門
- **關鍵詞：** `Chinese-English bilingual layout, CJK with Latin subtitle, large Chinese with small English annotation`

### 5. 極細字 × 大量留白
- 字重極細（Thin/Ultralight），周圍大量空白
- 文字像「刻」在空間裡，而非「印」在紙上
- 代表：向向走走、矛盾
- **關鍵詞：** `ultra-thin typeface, hairline weight, generous negative space, minimal characters maximum breathing room`

## 特殊排版形式

### 超大字佔版
- 一兩個字放大到佔滿整個版面
- 文字即構圖，字形邊緣就是畫面邊框
- 代表：說到愛、矛盾（兩字頂天立地）
- **關鍵詞：** `oversized Chinese character filling frame, type as image, full-bleed typography, character as composition`

### 仿古框 × 圖文混排
- 傳統印章框、線框、古典版式元素
- 圖像與文字在框架內共存，有版籍感
- 代表：龍來步道
- **關鍵詞：** `vintage frame typography, seal stamp aesthetic, traditional layout with modern photo, archival design sensibility`

### 密集小字作為質感層
- 大量小字密集排列，不以閱讀為目的，而是製造視覺紋理
- 通常作為背景層或輔助層
- 代表：夢想空間
- **關鍵詞：** `dense micro-text as texture, small text as visual pattern, layered typographic background`

## 文字即畫面（圖14 岡本003）

### 核心概念
文字不需要圖像輔助，本身就能構成完整畫面。
實際使用時可加入圖像元素，但排版骨架本身要能獨立成立。

### 文字透明度層次系統
同一個字/數字，用三種透明度同時出現製造空間感：
- **前景**：實色（100%不透明），最大最前
- **中景**：半透明（約40-60%），稍小稍退
- **背景**：輪廓字/描邊字（只有邊框，填色透明），最退最輕
- 三層疊加 → 製造景深，文字有了前後空間

**關鍵詞：**
```
layered text opacity, solid foreground type, semi-transparent midground,
outline stroke background text, typographic depth layers,
overlapping text at different opacities
```

### 超大數字/文字超出畫框
- 主視覺數字/文字放大到邊緣超出畫框裁切
- 「看不完整」反而製造更強的存在感
- 搭配透明度層次，形成前後空間
- **關鍵詞：** `oversized number bleeding off frame, cropped giant type, full-bleed typography, number as visual hero`

### 多語言疊加排版
- 日文 × 中文 × 英文 × 數字同時出現於同一畫面
- 不同語言承擔不同視覺角色：數字/英文→視覺衝擊，中日文→資訊補充
- 語言本身的字形差異製造豐富的視覺紋理
- **關鍵詞：** `multilingual typographic layout, Japanese Chinese English mixed, CJK Latin numeral overlay, language as texture`

### 斜體草寫 × 直立字對比
- 主標題用直立粗黑體，輔助文字用斜體/草寫感字體
- 兩種字形態度的衝突製造動態感
- **關鍵詞：** `italic script contrast with upright bold, oblique meets straight, dynamic type contrast`

## 圖文結合型字體設計（Logo / 標準字特殊處理）

> 當畫面涉及 Logo、品牌標準字、或需要字形本身承載圖像意義時，辨識並使用以下手法。

### 手法速查表

| 中文術語 | 英文術語 | 核心概念 | 典型特徵 |
|---------|---------|---------|---------|
| 圖文結合 | Combination Mark | 圖標 + 標準字合為一體 | 圖與字可分離但設計上整合 |
| 文字圖形化 | Illustrative Typography | 筆畫本身即插圖/符號 | 字的筆畫看起來像某個物件 |
| 嵌入式設計 | Integrated Icon | 圖示取代某字母或筆畫 | 某一筆畫被動物/符號/形狀替換 |
| 標準字設計 | Logotype Design | 品牌名客製化字形 | 筆畫有異質化處理，非通用字型 |
| 創意字體設計 | Creative Typography | 筆畫具藝術聯想轉化 | 筆畫形狀暗示某個意象 |
| 拆字法 | Deconstructed Typography | 拆中文筆畫置入元素 | 筆畫缺口或空間藏有圖示 |
| 負空間字體 | Negative Space Typography | 留白處隱藏第二層意義 | 字的空白區域藏有圖案 |

---

### 各手法 Prompt 關鍵詞

#### Combination Mark（圖文結合）
```
combination mark logotype, icon integrated with wordmark,
unified brand symbol and text, logo lockup design,
symbol and lettering as one unit
```

#### Illustrative Typography（文字圖形化）
```
illustrative typography, letterform as illustration,
typographic pictogram, stroke transformed into symbol,
pictographic letterform design
```

#### Integrated Icon（嵌入式設計）
```
integrated icon within letterform, icon replacing stroke,
character with embedded symbol, logotype with [動物/物件] silhouette replacing radical,
letterform substitution design
```
> 使用時將 `[動物/物件]` 替換為具體元素，例如：`cat silhouette replacing bottom radical`, `leaf replacing letterform stroke`

#### Logotype Design（標準字設計）
```
custom logotype design, bespoke letterform, 
hand-crafted wordmark, stroke variation lettering,
heterogeneous stroke weight, custom Chinese logotype
```

#### Deconstructed Typography（拆字法）
```
deconstructed Chinese character, stroke gap with embedded element,
radical replacement design, component substitution typography,
CJK character deconstruction with icon inlay
```

#### Negative Space Typography（負空間字體）
```
negative space logo design, hidden symbol in letterform,
counter space illustration, figure-ground reversal typography,
concealed image within character outline
```
