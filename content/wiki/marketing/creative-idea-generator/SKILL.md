# Creative Idea Generator

## 核心理念

好的廣告創意不是「描述產品」，而是**找到產品與人之間那個真實的情感連結點**，再用一個意外但合理的視覺跳躍讓人記住。

這個 skill 的工作是：從產品走到洞察，從洞察跳到概念，從概念翻譯成畫面。
輸出的視覺概念卡可以直接銜接 `image-prompt-generator` 使用。

---

## Step 0：模式判斷

先判斷是哪種使用情境，影響後續的洞察深度和語氣：

| 模式 | 觸發條件 | 特點 |
|------|---------|------|
| **Warren 品牌模式** | 出現「Warren」字詞 | 需符合 Warren 品牌調性（藍色系、5種情境色票）|
| **客戶服務模式** | 出現具體品牌名/產品名但非 Warren | 中立，不帶入 Warren 審美偏好 |
| **自由探索模式** | 純粹發想，無指定品牌 | 最大自由度，可提供多個方向 |

Warren 品牌模式下，創意概念輸出後需自動搭配對應的 Warren 情境色票建議（參見 `references/warren-creative-bridge.md`）。

## Step 1：產品解析

收到輸入後，先萃取以下資訊（未提供的自行推斷，並在輸出中標注「推斷」）：

### 四個維度

**① 產品本質**
- 它賣的表面上是什麼？（功能）
- 它賣的本質上是什麼？（感受/身份/時刻）
- 例：咖啡表面賣「提神」，本質賣「重新啟動的儀式感」

**② 使用時刻**
- 什麼情境下使用？（早晨/疲憊/慶祝/日常）
- 使用者當下的情緒狀態是什麼？
- 這個時刻對使用者的意義是？

**③ 目標族群**
- 誰在用它？（不只是人口統計，是生活狀態）
- 他們在意什麼？害怕什麼？渴望什麼？

**④ 競爭環境（選填）**
- 同類產品怎麼說自己？
- 有沒有還沒被說過的角度？
- ⚠️ **非商業機構**（博物館、公益組織、政府機關）：競爭者不是「同類機構」，而是「週末的所有選擇」（Netflix、夜市、購物中心）。請從「為什麼要選這個而不是其他任何事」的角度思考。
- ⚠️ **知識服務類別**（廣告/顧問/法律/設計/教育訓練）：洞察必須從**客戶的焦慮**出發，不是從服務提供者的能力出發。問：「客戶最怕什麼？」而非「我們能做什麼？」否則輸出會變成炫技而非溝通。
- ⚠️ **國家載體品牌**（旗艦航空、國營/半國營企業、品牌形象與國家符號強綁定的品牌，如華航、長榮、新加坡航空、ANA）：這類品牌同時運作三個層次——服務體驗 × 品牌認同 × **國家/文化身份認同**。洞察不能停在「服務好不好」，必須挖到「這個品牌跟消費者的身份認同有什麼關係」。核心問題：「搭這班飛機，消費者覺得自己是誰？」

## Step 2：洞察挖掘

> 這是整個流程最關鍵的一步。爛的洞察 = 爛的創意。

**洞察的定義：** 一個使用者從來沒有聽人說過、但一聽就覺得「對，就是這樣」的真實。

### 挖掘方法：五層追問

從產品的使用時刻出發，連問五次「為什麼這對人重要」：

```
產品/時刻
  → 為什麼重要？ [第一層：功能理由]
    → 為什麼這個感受重要？ [第二層：情感理由]
      → 為什麼這個情感重要？ [第三層：心理需求]
        → 為什麼有這個需求？ [第四層：社會/文化背景]
          → 這個需求揭示了什麼人性？ [第五層：人性洞察]
```

**範例：麥當勞咖啡**
```
咖啡（早晨）
  → 要提神 [功能]
    → 睡醒的人是「失靈」的狀態，需要重新運作 [情感]
      → 人需要一個「重啟的儀式」來告訴自己「今天開始了」 [心理]
        → 現代人的早晨越來越焦慮，需要一個可控的起點 [文化]
          → 人用小儀式對抗失控感 ← 洞察
```

### 輸出格式
選出**1個最強洞察**（可附2個備選），用一句話說清楚：

**一般品牌：**
> 「[目標族群] 在 [時刻] 需要的不是 [表面功能]，而是 [深層需求]。」

**奢侈品牌例外**（定價遠高於功能價值、以稀缺性為核心的品牌，如 Hermès、Rolex、頂級私人銀行）：
> 「[目標族群] 不是在尋找 [功能]，而是在確認自己 [身份/資格/姿態]。」
> 原因：奢侈品客戶不「需要」任何東西，他們在「選擇」——洞察邏輯與大眾品牌相反，強調「距離感」而非「親近感」。

**非商業機構例外**（博物館、公益組織、政府機關）：
> 「[目標族群] 以為 [機構] 不是為他們而設，其實 [真實的連結點]。」
> 原因：非商業機構最大的障礙不是競爭對手，而是「這跟我有什麼關係」的距離感。

## Step 3：創意跳躍

從洞察跳到視覺概念。這一步要找「意外但合理的連結」。

### 跳躍技法（每次至少嘗試3種，選最強的）

**① 視覺隱喻**
把洞察中的抽象概念，找一個具體物件來承載。
> 洞察「重啟儀式」→ 咖啡 cream = 鬧鐘刻度（時間啟動的視覺符號）

**② 尺度顛覆**
把日常物件放大/縮小到不合理的尺寸，製造衝擊。
> 一個巨大的咖啡杯出現在城市早晨的街道上，行人從它旁邊走過

**③ 時間扭曲**
展示「使用前/使用後」的極端對比，或把時間壓縮/延展。
> 畫面左側是還沒喝咖啡的灰色世界，第一口入喉後色彩瞬間飽和

**④ 物件錯置**
把產品放進它「不該在」的場景，製造衝突感。
> 辦公室裡所有東西都是咖啡色，只有那杯咖啡是彩色的

**⑤ 角色轉換**
讓產品成為人，或讓人成為產品的一部分。
> 咖啡的蒸氣慢慢形成一個人的輪廓，從杯子裡「站起來」

**⑥ 反向操作**
把品牌通常訴求的反面說出來，反而更有力。
> 「你不需要它。（但每個人都需要它。）」

**⑦ 情緒具象化（專為抽象服務/B2B 設計）**
當產品是軟體、保險、金融、諮詢等無形服務時，不要視覺化「產品本身」，而是視覺化「有它vs沒它的感受差異」，用人的身體狀態或空間氛圍來承載無形的價值。
> ERP 軟體 → 不視覺化軟體介面，而是視覺化「終於睡得著的老闆」
> 保險 → 不視覺化保單，而是視覺化「下雨天，但我知道我沒問題」
> 關鍵原則：找到有它時「身體會放鬆的那個時刻」，用那個姿態/表情/空間說話

### 輸出格式
每個概念輸出一張「創意卡」，**最多輸出3個概念**，並標注主推/備選。
每張創意卡包含兩個區塊：**視覺區塊 + 文案區塊**，兩者同步產出。

```
💡 [主推] 概念名稱：[給這個概念取一個短名]

── 視覺區塊 ──
核心洞察：[一句話]
創意跳躍：[用了哪個技法 + 一句話說概念]
畫面描述：[具體到可以在腦中看到的一段描述，50字以內]
情緒目標：[看到這張圖，觀者的第一個感受是什麼]
適合媒體：[社群/海報/影片/OOH 戶外廣告]
為何主推：[這個概念最符合品牌/目標/洞察的理由，一句話]

── 文案區塊 ──
[根據「適合媒體」和「品牌調性」自動決定輸出哪些元素，規則見 Step 3.5]

---

💡 [備選] 概念名稱：...
（同上格式）
為何備選：[和主推的策略差異是什麼，一句話]
```

## Step 3.5：文案生成規則

> 文案是洞察的語言版本。好文案不解釋廣告，它本身就是廣告。
> 文案區塊緊接在每張創意卡的視覺區塊之後，自動輸出，不需要使用者另外要求。

### 輸出元素的判斷邏輯

根據「適合媒體」自動決定輸出哪些文案元素：

| 媒體類型 | 主標 | 副標 | CTA | Icon方向 |
|---------|------|------|-----|---------|
| 社群廣告（IG/FB） | ✅ 必要 | ⭕ 選用 | ✅ 必要 | ⭕ 選用 |
| 海報 / 印刷 | ✅ 必要 | ✅ 必要 | ⭕ 選用 | ⭕ 選用 |
| OOH 戶外看板 | ✅ 必要（僅一句，≤8字） | ❌ 不輸出 | ❌ 不輸出 | ❌ 不輸出 |
| 影片 | ✅ 旁白第一句 | ⭕ 片尾字卡 | ✅ 片尾CTA | ❌ 不輸出 |
| 品牌形象廣告 | ✅ 必要 | ✅ 必要 | ❌ 不硬銷 | ⭕ 選用 |
| B2B / 知識服務 | ✅ 必要 | ✅ 必要 | ✅ 必要 | ⭕ 選用 |

### 語言選擇邏輯

主體文案以**繁體中文**為主。依品牌調性自動附加語言：

| 品牌調性 | 附加語言 | 原因 |
|---------|---------|------|
| 奢侈品 / 國際時尚 / 高端精品 | 英文 | 英文帶距離感與國際質感 |
| 日系品牌 / 精緻生活 / 療癒系 | 日文 | 日文強化細膩與職人感 |
| 在地台灣品牌 / 大眾消費 / 公益 | 純繁中 | 不需要語言區隔感 |
| 科技 / 新創 / 年輕族群 | 英文副標或 Slogan | 英文增加現代感 |
| 國家載體品牌（如華航） | 中英並列 | 對應國內外雙向受眾 |

### 各元素的寫作原則

**主標（Headline）**
- 不超過12個中文字（OOH ≤8字）
- 說感受，不說功能——用洞察語言而非產品語言
- 測試標準：拿掉品牌名還有力量嗎？有，才是好主標

**副標（Subline）**
- 補充主標沒說完的，不重複主標的意思
- 可以帶功能，但用情感語言包裝
- 建議15字以內

**CTA（Call to Action）**
- 根據品牌調性調整語氣，不只是「立即購買」：
  - 奢品：邀請感——「探索」「預約」「感受」
  - 大眾消費：行動感——「現在試試」「今天就來」
  - 公益：參與感——「加入我們」「你也可以」
  - B2B：具體感——「申請試用」「預約 Demo」「索取提案」

**Icon 方向**
- 不設計具體 icon，給概念方向：形狀 + 象徵 + 與洞察的關聯
- 例：「向上弧線，象徵輕盈與超越，呼應『不被地面限制』的洞察」
- 例：「打開的手掌，象徵給予與邀請，對應『美是為所有人準備的』」

### 文案區塊輸出格式

```
── 文案區塊 ──

📌 主標
  繁中：[主標文案，≤12字]
  [若有附加語言]：[對應文案]

📝 副標（海報/品牌形象/B2B 適用）
  繁中：[副標文案，≤15字]

👆 CTA（社群/影片/B2B 適用）
  [文案] ── 語氣：[邀請 / 行動 / 參與 / 具體]

🔵 Icon 方向（品牌識別需求強時適用）
  [形狀概念] ＋ [象徵意義] ＋ [與洞察的關聯]

💬 備用主標（2個方向）
  ① 情感路線：[文案]
  ② 衝擊/反向路線：[文案]
```

## Step 4：視覺概念卡輸出（銜接 image-prompt-generator）

選出最強的 1-2 個概念，先輸出視覺概念卡，再顯示銜接詢問框。

### 4a｜視覺概念卡（固定輸出）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
🎯 視覺概念卡 ── 可直接貼給 image-prompt-generator
━━━━━━━━━━━━━━━━━━━━━━━━━━

【概念】[概念名稱]

主體：[畫面最重要的東西是什麼]
情緒：[用2-3個情緒詞描述感覺]
用途/平台：[這張圖用在哪]
核心概念關鍵詞：[概念的視覺符號，3-5個詞]
風格傾向：[寫實/平衡/創意端，可用光譜1-10，並一句話說明為何選這個風格]

[若為 Warren 品牌模式，附加：]
品牌色情境：[奢華/時尚/文青/商業/消費，選一個]
Warren Blue 在畫面中的角色：[如何出現]

━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 4b｜銜接詢問框（視覺概念卡輸出後，立刻顯示）

視覺概念卡輸出完畢後，**必須顯示以下詢問框，等待使用者回應後才繼續**：

```
──────────────────────────────
🔗 要把文案一起帶進去嗎？

已為這個概念生成了文案建議（主標、副標、CTA 等）。
你可以選擇是否將文案同步加入視覺概念卡，讓 image-prompt-generator 在生成圖片時也考慮排版與文字空間。

請選擇：
  A｜帶入文案  ── 在概念卡補上文案欄位，Prompt 會預留文字版面空間
  B｜不帶入    ── 保持純視覺概念卡，圖片以畫面為主，不排版文字
  C｜自訂文案  ── 我想修改文案內容後再帶入
──────────────────────────────
```

**使用者選 A（帶入文案）：**
在視覺概念卡末尾補上文案欄位，輸出完整版概念卡：

```

━━━━━━━━━━━━━━━━━━━━━━━━━━

【概念】[概念名稱]

主體：[畫面最重要的東西是什麼]
情緒：[用2-3個情緒詞描述感覺]
用途/平台：[這張圖用在哪]
核心概念關鍵詞：[概念的視覺符號，3-5個詞]
風格傾向：[寫實/平衡/創意端，可用光譜1-10，並一句話說明為何選這個風格]

── 文案資訊（供排版參考）──
主標：[主標文案]
副標：[副標文案，若有]
CTA：[CTA 文案，若有]
文字排版提示：[預留文字版面的位置與比例，供 Prompt 生成時參考]

[若為 Warren 品牌模式，附加品牌色欄位]

━━━━━━━━━━━━━━━━━━━━━━━━━━
→ 複製以上內容，貼入 image-prompt-generator 即可生成畫面
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**使用者選 B（不帶入）：**
直接在原視覺概念卡末尾加上提示：
```
━━━━━━━━━━━━━━━━━━━━━━━━━━
→ 複製以上內容，貼入 image-prompt-generator 即可生成畫面
（純視覺版，圖片以畫面構成為主）
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**使用者選 C（自訂文案）：**
顯示現有文案讓使用者修改：
```
目前的文案建議如下，請直接告訴我要修改哪一項：

主標：[現有主標]
副標：[現有副標，若有]
CTA：[現有CTA，若有]

修改後，我會重新組合成完整的視覺概念卡。
```
收到修改後，執行與「選 A」相同的流程，帶入修改後的文案。

## 品質自我檢查

每次輸出前確認：
- [ ] 模式判斷正確（Warren/客戶/自由探索）？
- [ ] 洞察是否真的是「洞察」而非「功能描述」？（測試：使用者聽到會點頭說「對，就是這樣」嗎？）
- [ ] **特殊類別檢查：**
  - 奢侈品牌 → 用的是「確認身份」邏輯，而非「需要/功能」邏輯？
  - 非商業機構 → 競爭環境是「所有週末選擇」，而非「同類機構」？
  - 知識服務 → 洞察從客戶焦慮出發，而非從自身能力出發？
  - 國家載體品牌 → 挖到了「國家/文化身份認同」那一層，而非停在服務體驗？
  - 抽象服務/B2B → 嘗試了技法⑦情緒具象化？
- [ ] 至少嘗試了 3 種跳躍技法？
- [ ] 多個概念時，有標注「主推/備選」並說明策略差異？
- [ ] 畫面描述是否具體到可以在腦中看到？
- [ ] **文案區塊檢查（Step 3.5）：**
  - 根據「適合媒體」判斷，輸出了對應的文案元素（主標/副標/CTA/Icon）？
  - 主標是否說「感受」而非「功能」？拿掉品牌名還有力量嗎？
  - 語言選擇是否符合品牌調性（繁中主體 + 必要時附加英/日）？
  - CTA 語氣是否符合品牌調性（邀請/行動/參與/具體）？
  - 備用主標提供了 2 個不同方向？
- [ ] 視覺概念卡的「風格傾向」欄位有附上理由說明？
- [ ] 視覺概念卡格式是否完整、可直接貼給 image-prompt-generator？
- [ ] Warren 品牌模式下，是否附上品牌色情境建議？
